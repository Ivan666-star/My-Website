# Prism

Prism 是用于考研复习的动态网站，包含三个科目入口：**英语、数学、信号与系统**。英语提供每日阅读、精读解析、词汇与写作训练；数学和信号与系统提供拍照或手动录题、错题管理与间隔复习。账号之间的学习数据独立保存。

> 界面上的“英语”“数学”是简短名称。英语内容仍以**考研英语一**为训练标准，数学模块仍覆盖数学一的高等数学、线性代数和概率论与数理统计。

## 使用说明

- [英语学习使用说明](docs/英语学习使用说明.md)：英语每日阅读、精读、素材与仿写。
- 数学：进入“数学”后，在错题库拍照或手动录入题干，选择高等数学、线性代数或概率论与数理统计；可先刷题再查看 AI 解析。
- 信号与系统：进入同名科目，录题和复习方式与数学相同，数据按科目隔离。
- [开发与 GitHub 同步](docs/开发与同步.md)：本机项目目录、提交方法和私有数据边界。

## 本机启动

1. 安装 Python 3.11 或更新版本，在项目根目录执行 `python -m pip install -r requirements.txt`。
2. 将 `.env.example` 复制为 `.env`，按需填写 `AI_BASE_URL`、`AI_MODEL` 和 `AI_API_KEY`。不要把 `.env` 上传到 GitHub。
3. 双击 `start.cmd`，或运行 `python -m uvicorn app.main:app --host 0.0.0.0 --port 8848`。
4. 在浏览器打开 <http://127.0.0.1:8848>。首次对外开放前，先创建管理员账号并确认登录保护生效。

`data/app.db` 保存账号、密码校验值和登录会话；每位用户的文章、学习记录、错题及图片单独存放在 `data/users/<用户ID_用户名>/`，其中数据库为 `learning.db`、图片位于 `math_images/`。旧数据拆分前会在 `data/backups/` 留存可校验的数据库备份。`data/` 中的内容不要删除或上传。没有 AI 密钥仍可浏览内置示例、手动录题；AI 生成与分析功能需要有效密钥。

## 公网测试和部署

本机可通过 Cloudflare Tunnel 临时提供 HTTPS 测试地址。该地址连接到这台电脑上的网站，电脑关机、休眠或断网时无法访问；临时 Tunnel 重启后通常会换地址。Tunnel 的本机配置和密钥不属于公开源码。

本项目的后端是 FastAPI，学习数据保存在 SQLite。不能只把 `web/` 上传到静态托管平台来获得登录、AI 和题库功能。长期在线部署需要持续运行 Python 后端，并为数据库、图片和环境变量配置持久存储。现有服务器部署资料见 [部署步骤](deploy/README_部署步骤.md)。

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `app/` | FastAPI 接口、账号、AI 流水线、数学和信号错题库。 |
| `web/` | 页面、样式、交互代码和 PWA 静态资源。 |
| `seeds/` | 英语内置示例内容。 |
| `deploy/` | 服务器部署示例和操作说明。 |
| `tools/` | 维护及测试脚本。 |
| `docs/` | 中文使用和开发说明。 |
| `.env.example` | 可公开的配置模板。 |
| `data/`、`.env` | 本机私有数据和密钥，不进入 GitHub。 |

目前用于短期测试。公开仓库只同步源码；测试账号、文章、错题、图片和 AI 密钥仍保存在本机。
