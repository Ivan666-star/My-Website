# Prism · AI 考研英语一长期训练系统

> V1（第一等级）已完成实现，按《AI 考研英语一长期训练系统 实施规格书》第三十二节与第四十一节验收标准落地。
> 形态：**网页 / PWA**，手机浏览器直接打开即可用，无需小程序、无需应用商店。

---

## 一、三步开始使用

### 1）配置 AI 模型（只需一次）

在项目根目录找到 `.env.example`，复制一份改名为 `.env`，填入你的模型信息：

```ini
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
AI_API_KEY=你的密钥
```

支持任何 OpenAI 兼容接口：DeepSeek、智谱 GLM、通义千问、Kimi、OpenAI、本地 Ollama。
只想先看看效果、还不想配密钥？**直接跳到第 2 步**——系统内置了两天的完整示例内容，功能全部可以走通。

### 2）启动服务

先在项目目录执行 `python -m pip install -r requirements.txt`。Windows 双击 **`start.cmd`**
（或执行 `python -m uvicorn app.main:app --host 0.0.0.0 --port 8848`）。

### 3）打开使用

| 场景 | 地址 |
|---|---|
| 电脑上打开 | http://127.0.0.1:8848 |
| 手机上打开 | 手机与电脑处于同一局域网时，访问电脑的局域网 IP 和 8848 端口 |

> 手机访问需要电脑防火墙允许 8848 端口入站；若网络策略禁止入站连接，需部署到服务器。
> `http://` + 局域网 IP 不支持 Service Worker，离线功能和完整的 PWA 安装体验需要 HTTPS。
> 公网部署方式见 `deploy/README_部署步骤.md`。上线前请创建管理员账号并配置访问控制。

## 二、每天怎么用（30～40 分钟）

1. **今日阅读**：打开只看到英文正文，**默认不显示翻译和解析**，先自己读（页面自动计时）。
2. 读完点 **「我读完了，展开解析 →」**。
3. 按顺序精读：
   - 🇨🇳 中文翻译（逐段对照 + 翻译要点说明）
   - 🔤 今日词汇（每个词可标「不认识 / 重点学习 / 已掌握」，或 ☆ 收藏）
   - 📐 今日长难句（4 句，可展开看主干、从句、修饰、为什么难）
   - 🧠 今日语法（3～4 个，均带文中真实例句）
   - 🔍 阅读逻辑（篇章结构、作者态度、阅读策略）
4. 📝 **今日写作表达**：3 个词/搭配 + 2 个句型模板，每条都标好**该用在作文的哪一段**和**属于什么文体**，可一键「加入作文素材库」。
5. ✍️ **今日仿写**：看着中文提示自己写英文 → 提交 → AI 批改（评分、逐条问题、润色版、推荐升级表达）→ **按建议改完再提交一次**。
6. 📊 今日学习情况：阅读用时、标记词汇、仿写次数与得分。

右上角五个按钮分别是 **今日复习**（带角标，数字=今天该复习多少条）、**素材库**、**学习数据（周报）**、**历史与真题**、**设置**。

## 二·五、素材库：收藏即自动分类（V2 核心）

每次点「☆ 加入作文素材库」时，系统会**立刻让 AI 判断四件事**，然后自动归位，不需要你做任何选择：

| 判断 | 取值 |
|---|---|
| **进哪个库** | 📝 作文素材库（能直接写进作文的句型 / 搭配 / 观点表达）／ 📖 阅读积累库（为读懂服务的词汇与长难句） |
| **主题分类** | 教育学习 / 科技发展 / 社会现象 / 环境保护 / 文化交流 / 人生哲理 / 经济就业 / 品质精神 / 通用表达 |
| **用在作文哪里** | 开头段 / 过渡段 / 主体段 / 结尾段 / 通用 |
| **属于什么文体** | ⚖️ 议论文 / 📊 说明文 / ✉️ 应用文 / 🖼️ 描写文 / 📖 记叙文 / 🔗 通用文体 |

**「文体」这一维专门回答「这条素材适合写进哪一类文章」**，因为考研英语一的大小作文文体完全不同：

| 文体 | 什么时候拿它出来用 |
|---|---|
| ⚖️ 议论文 | 大作文主体：立论、分析原因、论证观点、提出建议 |
| 📊 说明文 | 客观陈述现象、数据、趋势，如 `According to the chart…` |
| ✉️ 应用文 | **小作文专用**：书信、邮件、通知、告示、备忘录、纪要的措辞 |
| 🖼️ 描写文 | 图画、场景、人物描写，常用于大作文首段 `As is vividly depicted…` |
| 📖 记叙文 | 讲述经历或案例，可放进举例论证里 |
| 🔗 通用文体 | 议论文、说明文、应用文都能用 |

> 例：收藏 `I am writing to express my sincere gratitude for…` 会自动判为
> **作文素材库 · 开头段 · 应用文**——一眼就知道这是小作文（书信）专用，别写到大作文里。

收藏成功的提示会直接告诉你结论，例如：

> 已归入【作文素材库 · 结尾段 · 议论文】　用在结尾段：总结观点、提出建议或升华主题

打开素材库（右上角 📚，或访问 `http://127.0.0.1:8848/#library`）可以：

- 按 **库** 切换，按 **位置** 和 **文体** 两级筛选，按「位置 / 文体 / 主题」三种方式分组浏览
- 每条素材能看到 **位置徽标（实心）+ 文体徽标（描边）+ 主题 + 置信度 + A/B/C 提分等级**，以及一句话使用建议
- 卡片上带「文体分布」小结，随时知道自己的素材是议论文多还是应用文多
- **手动纠偏**：AI 判断不合你意时，点「调整分类」直接改位置和文体；点「↻ AI 重新归类」让它重判一次
- 底部有完整的 **位置说明** + **文体说明** 速查表

> 设计取舍：AI 归类是**建议**不是命令。所以每条都留了手动改的入口，改了之后会标记为「手动 / 规则」，
> 之后再点「AI 重新归类」才会被覆盖——不会出现你改完又被 AI 冲掉的情况。

素材库在没有配置 AI 时也能用：会用关键词规则兜底归类（文体同样能判，例如
`Dear Sir… / I am writing to…` → 应用文，`As is vividly depicted…` → 描写文，
`According to the chart…` → 说明文，`Last summer I…` → 记叙文），功能不缺失。

> 升级说明：新增「文体」维度后，服务启动时会自动为**已有素材**用规则补齐文体标签
> （纯本地判断，不调模型、不产生费用），所以老素材打开就有标签，不会出现空白。

## 二·六、素材库搜索（不要翻半天）

素材库顶部有一个搜索框，**空格分隔多个关键词 = 同时满足（AND）**，大小写不敏感。
匹配范围覆盖：英文原文、中文意思、例句、使用建议、主题分类、标签。

比如搜 `the oppor`，会命中所有**同时**含 `the` 和 `oppor` 的素材；搜 `开头 书信`
只留下开头段的应用文书信表达。命中的关键词会用黄色高亮标出来。

搜索框在打字时不会失焦、光标不会跳（渲染后会恢复焦点和光标位置），可以连续输入。
清空按钮在输入框右侧，一点就回到完整列表。

> 搜索和 **库 / 位置 / 文体** 三级筛选是叠加生效的——先筛出「结尾段 + 议论文」，
> 再在里面搜关键词，一层层收窄。

## 二·七、今日复习：收藏即自动进入间隔重复（不要收藏完就忘）

**收藏素材的那一刻，它就自动进入了复习节奏**，不需要你额外开启任何开关。
第二天打开网页，右上角「今日复习」按钮上会出现角标，告诉你今天该复习几条。

复习卡片的设计是**先考后看**：只给你英文，先自己回忆它的意思和用法，再点「看答案」看中文、
使用建议和例句，然后选：

| 你的选择 | 系统怎么做 |
|---|---|
| **记住了** | 间隔往后走一档 |
| **忘记了** | 退回 1 天后重来 |
| **稍后** | 推到明天，进度不变 |
| **不再复习** | 退出循环（**素材还留着**，只是不再提醒） |

间隔阶梯固定为 **1 → 2 → 4 → 7 → 15 → 30 → 60 天**。
第 1 次记住后 1 天再见，第 7 次记住后 60 天再见——走完整条阶梯就标为 **已巩固**。

被「不再复习」移出的素材，卡片上会出现 **「↻ 重新加入复习」**，随时可以拉回来。

> 复习不是背单词软件那种纯记忆。考研英语一的作文素材要的是「能在考场上想得起来、用得对」，
> 所以这里考的是**意思 + 该用在作文哪一段 + 例句**，跟素材库的分类是一致的。

## 二·八、真题精读（和每日外刊汇进同一个素材库）

「历史与真题」里有两个页签：**每日内容** 和 **真题精读**。

真题精读的用法是**精读用法，不是模考用法**——把做完的真题原文整篇粘进来，
AI 会按**真题模式**解析，和每日外刊走同一套流程，但侧重点不同：

- **词汇**：优先收「真题高频、且常被用来设置正确选项或干扰项」的词与搭配
- **长难句**：优先挑「真题最爱设题的句子」——观点句、转折句、因果句、例证定位句
- **阅读逻辑**：结合考研阅读出题套路给策略建议
- 好表达一样可以一键收进素材库，和每日外刊的素材**汇进同一个库**，统一复习

**什么时候用哪种用法：**

| 阶段 | 怎么用真题 |
|---|---|
| 现在 ～ 2027 年 6 月 | **精读用法**：用 2012 年以前的题逐篇拆解，练词汇、长难句、设题点 |
| 2027 年 7 ～ 10 月 | 精读 + 分题型专项（把早年的题按题型再过一遍） |
| 2027 年 11 ～ 12 月 | **模考用法**：最近 3 年（2024–2026）的题按考试时间整套做，掐表 |

> ⚠️ **红线：最近 3 年的真题（2024–2026）不要拿去精读。**
> 模考的价值来自「第一次见」——提前精读掉，模考就测不出真实水平了。
> 导入表单在选择这些年份时会弹窗确认，页面下方也常驻这条提示。
>
> 年份区间来自配置 `EXAM_TARGET_YEAR`（默认 2027），改这一个值，下拉框和提示会一起跟着变。

**导入入口**：右上角「历史与真题」→ 真题精读页签 → 「＋ 导入一篇真题」，
或在首页空状态点「🎯 导入真题精读」。选年份、选篇目（完形 / 阅读 Text 1–4 / 新题型 / 翻译）、
粘贴原文（300 词以上），等 1～2 分钟。
解析完成后会直接切到真题精读界面，解析内容里同样可以收藏素材、可以提交仿写。

> 技术上真题复用了每日外刊的整套精读结构，所以「收藏 → 归类 → 进复习节奏」这些流程
> 对真题**完全一致**。区别只是真题存在一个特殊日期位（如 `exam-2010-text2`），
> 因此**永远不会和每日内容串台**：历史列表里看不到真题，每日内容也不会被真题顶掉。

## 三、自动化：每天自动准备好内容

系统内置了调度：**只要服务在运行**，每天 `DAILY_GENERATE_HOUR`（默认 6 点）之后会自动检查并生成当天内容，无需手动点。

也支持外部调用（Harness / Windows 计划任务 / 定时脚本）：

```bash
python -m tools.daily generate     # 生成今天的内容（已有则跳过）
python -m tools.daily generate --force --topic 科技与人工智能
python -m tools.daily weekly       # 打印最近 7 天数据
python -m tools.daily check        # 健康检查
```

想接 Harness，直接让它定时执行上面第一条命令即可。

## 四、系统是怎么「越用越懂你」的（V1 已具备）

| 能力 | 实现方式 |
|---|---|
| 动态难度 | 最近 3 次仿写均分 ≥8 上调难度；≤5 下调；生词占比连续偏高也下调（1～5 档） |
| 主题不重复 | 从题材池中排除最近写过的主题 |
| 生词复现 | 标记为「不认识 / 重点学习」的词，会被写进下一篇的生成要求里，优先复现 |
| 语法针对性复现 | 长期高频出现的语法点，会在后续文章中被要求增加 |
| 长期数据 | 每篇文章、每个词、每次仿写、每次标记、每次阅读时长都落库；`events` 表记录全部行为流 |
| 周报 | 学习数据面板：篇数、词数、时长、掌握分布、待攻克词汇、高频语法、仿写均分 |

## 五·五、手机在外面也能用（部署到云服务器）

默认这套系统跑在你自己的电脑上：**电脑开着，同一个 WiFi 下手机才能用**。
想让手机在任何地方都能打开（而且不用带电脑），需要把它放到一台云服务器上。

完整操作手册在 **`deploy/README_部署步骤.md`**，这里只讲三个要点：

**1）为什么必须有登录（两种方式，二选一）**

系统**默认没有任何登录**。一旦挂到公网，任何拿到网址的人都能看到你的全部学习数据，
并且能用你的 API Key 去花钱。所以对外暴露之前，必须让登录门生效：

**方式 A · 账号密码（推荐，多人用就选它）**

打开网址 → 出现登录页 → 输账号密码进入。**每人一个账号，数据各自独立**。

开号有两种途径：

1. **让别人自己申请**：把注册页地址发给他（登录页也有「自己申请一个」的入口）：
   `https://你的域名/register`。他填完用户名密码会显示「申请已提交」，
   但**此时还登不进去** —— 你在 **设置 → 用户管理** 顶部会看到「N 条申请待批准」，
   点「批准」他才能用；不认识的人点「拒绝」即可（账号删除、用户名释放，他可以重申请）。
   不想要自助注册，就在 `.env` 里设 `ALLOW_SELF_REGISTER=0` 关掉入口。
2. **你直接给他开**：**设置 → 用户管理 → 添加账号**，建好即可用（无需再批准）。

上线后第一次打开网站会引导你创建管理员账号（你自己）。**先给自己建号，再给别人开号**
（老数据归第一个账号）。创建首个账号需要一个「初始化码」，来源优先级从高到低：

1. `.env` 里的 `SETUP_CODE`
2. `.env` 里的 `ACCESS_PASSWORD`
3. 都没设 → 系统自己随机生成一个，打印在启动日志里，并写到 `data/setup_code.txt`

> 在本机用 `127.0.0.1` 直连访问时**免初始化码**，方便你先在本地把号建好再上线。

**方式 B · 共用口令（简单，但所有人共用一份数据）**

```
ACCESS_PASSWORD=一个 10 位以上、别用生日手机号的口令
```

打开网址输这个口令，输一次记一年；改口令 = 所有设备立刻掉线。

**两种都没设 = 完全不介入**，本地自用的行为和以前一模一样。

**2）部署的核心好处不是"能在外面上网"，而是每日内容自动化**

以前「每天 6 点自动出题」必须你的电脑开机、服务在跑。
放到服务器上之后，服务器 24 小时替你干活，你早上起来内容已经备好了。

**3）上线之后统一用一个网址**

手机、平板、家里电脑 —— 全部访问 `https://你的域名`，**不要再开本机那个**。

> 原因：SQLite 是单机数据库。如果家里一份、服务器一份，两边各记各的，
> 数据很快就会分叉，而且没法自动合并。统一一个入口就永远只有一份数据。

手机浏览器里用「添加到主屏幕」，图标点开就是全屏，和 App 没区别。

## 六、数据与备份

- 所有数据都在 **`data/app.db`**（SQLite，单文件）。想备份，复制这一个文件即可。
- 想清空重来：删掉 `data/app.db`，重启服务，会重新写入示例内容。
- AI 密钥只存在于 `.env`，**不会**进入数据库。
- 账号密码进数据库，但存的是 **PBKDF2-HMAC-SHA256 / 20 万轮** 的不可逆摘要，
  每人独立加盐；登录会话在库里也只存 **SHA-256 摘要**。所以就算 `app.db` 被拿走，
  也没法直接还原出密码或伪造登录。
- **服务在跑的时候不要直接 `cp` 数据库文件**：可能复制到"写了一半"的状态。
  用 `sqlite3 app.db ".backup '备份目标.db'"` 拿快照，或直接用 `deploy/backup_db.sh`。
- 部署到服务器后，`deploy/backup_db.sh` 会每天凌晨 4 点自动备份并保留 14 天。

## 八、常见问题

**Q：页面提示「尚未配置 AI 模型」？**
A：填好 `.env` 里的 `AI_API_KEY` 后重启服务即可。不配置也能用，只是内容固定为内置示例。

**Q：生成一篇要多久？**
A：约 1～2 分钟（文章、解析、写作任务三次模型调用）。

**Q：手机上打不开？**
A：确认手机与电脑在同一 WiFi；确认 `.bat` 窗口没有关闭；Windows 防火墙首次会弹窗，选「允许访问」。

**Q：能不能换模型？**
A：改 `.env` 里的 `AI_BASE_URL` / `AI_MODEL` / `AI_API_KEY`，重启即可。想让长难句分析和作文批改走更强的模型，填 `AI_MODEL_STRONG`。

**Q：一篇大概花多少 token / 多少钱？**
A：每天约 1～3 万 tokens。用 DeepSeek 这类模型，一个月几块钱。

**Q：复习的间隔能改吗？**
A：能。阶梯在 `app/db.py` 的 `REVIEW_INTERVALS`（默认 `[1,2,4,7,15,30,60]` 天），
「已巩固」的门槛是走完整条阶梯（`MASTERED_AT` 自动等于阶梯长度，不用手动同步）。
改完重启服务即可，已经排好的复习日期不会被改，只影响之后的推进。

**Q：导入真题会不会把每日外刊的内容顶掉？**
A：不会。真题存在一个独立日期位（如 `exam-2010-text2`），每日内容按真实日期查，
两边**永远不会撞**。历史列表只显示每日内容，真题在「真题精读」页签里单独列。
同一篇真题重复导入是**覆盖**，不会产生两条。

**Q：多人一起用，会不会互相看到对方的数据？**
A：不会。每人一个账号，数据按账号存，接口层还会做归属校验 —— 就算手动改网址里的
id 去访问别人的记录，也会被挡掉（返回 404 / 403）。管理员能改别人的密码、能停用账号、
能批准/拒绝他人的申请，但**看不到别人的学习内容**。想加人，让他自己上 `/register`
申请、你点批准，或在「用户管理」里直接开号，都不用重启服务。

**Q：别人自己申请了账号，为什么还是登不进去？**
A：这是设计如此 —— 自助申请建出来的是**「待批准」**账号。你得在 **设置 → 用户管理**
顶部的「N 条申请待批准」里点「批准」，他才能登录。这样即使注册网址被陌生人拿到，
也进不来。不想开放自助注册就设 `ALLOW_SELF_REGISTER=0`。

**Q：忘了密码怎么办？**
A：让另一个管理员在「用户管理」里重置。如果只有一个管理员而且忘了，目前没有自助找回，
告诉我，我从数据库层面处理（学习数据不会动）。

**Q：老数据（没有账号之前攒的）去哪了？**
A：迁移时统一放进一个"无主"位置，**第一个建好的账号会自动认领全部老数据**。
所以先给自己建号，再给熟人开号，顺序别反。

**Q：我提前精读了最近的真题，怎么改掉那个红线年份？**
A：改 `.env` 里的 `EXAM_TARGET_YEAR`（比如你提前考，就把它改成对应年份），
年份下拉框和红线提示会一起跟着变，不用改代码。
