# 数学与信号题库隔离修正

## 发现的问题

1. 两科共用每日时间预算与已练数量，完成数学题会减少信号的建议名额。
2. 草稿虽然记录了所属科目，显示、「全部保存」和「关闭」仍处理所有草稿。
3. 详情、修改、删除、补答案和提交复习结果只检查账号，没有核对当前题库。
4. 科目切换后，旧的随机刷题或详情请求可能迟到，覆盖当前科目的页面。
5. 首页从混合统计中手动拆科目，数学的「未分类」题可能漏计；识图提示也曾同时提供两科分类。

## 错误代码与正确代码

### 1. 复习进度和任务

错误代码：

```python
daily = daily_selection(date.today(), exam_date())
slots = max(0, capacity - len(done))
```

正确代码：

```python
daily = daily_selection(date.today(), exam_date(), module)
# SQL 同时限定账号与 module 对应的科目。
# 到期任务全部计数，页面按 next_offset 连续加载，不设时间预算或固定题数上限。
```

原来把两科当成一份任务，既会串进度，也会把超出建议名额的题放到另外的入口。现在两科独立计算到期题和今天已练；同题当天多次练习只计一道。旧时间设置不再影响任务数量。

### 2. 草稿显示、保存和关闭

错误代码：

```javascript
MATH.drafts.map(draftCard);
const list = MATH.drafts.filter(draftReady);
MATH.drafts = [];
```

正确代码：

```javascript
const drafts = MATH.drafts.filter(d => d.module === MATH.module);
const list = notebookDrafts().filter(draftReady);
MATH.drafts = MATH.drafts.filter(d => d.module !== MATH.module);
```

原来只在草稿创建时记录科目，后续操作没有使用这个标记。现在当前页面只能显示、保存或关闭当前科目的草稿；另一科的草稿继续留在原入口。保存状态也分别记录。

### 3. 后台题目操作

错误代码：

```python
def api_detail(pid: int):
    row = _row(_get(pid), with_analysis=False)
```

正确代码：

```python
def api_detail(pid: int, module: str = "math"):
    row = _row(require_problem(pid, module), with_analysis=False)
```

原来同一账号拿到另一个科目的题号就能读取或修改。现在每个题目接口同时核对账号和题库；跨科目操作返回 404，不修改答案或复习记录。录入和修改分类也拒绝跨科目，图片识别任务及防重复保存编号分别限定题库。

### 4. 旧请求覆盖新页面

错误代码：

```javascript
const r = await api("/api/math/random?module=" + MATH.module);
MATH.drill = r.problem;
```

正确代码：

```javascript
const module = MATH.module, epoch = MATH.loadSeq;
const result = await api(notebookUrl(path, module), options);
if (MATH.module !== module || MATH.loadSeq !== epoch || currentView !== "math") {
  throw new Error("页面已切换，操作结果已留在原题库，请返回查看");
}
```

网络请求发出后可能过几秒才返回；这期间用户已经切换题库。现在响应返回时再次核对题库与页面版本，阻止旧内容写入新页面。列表、日历和复习队列同样保留响应核对。

### 5. 分类与首页统计

错误代码：

```javascript
const m = await api("/api/math/meta");
// 从混合的 by_subject 手动拆出两个科目。
```

正确代码：

```javascript
const [math, sig] = await Promise.all([
  api("/api/math/stats?module=math"),
  api("/api/math/stats?module=sig"),
]);
```

现在首页直接取各科的独立统计，数学包含历史未分类题。分类选项、识图提示和复习阶段校正也分别限定科目，识图结果若落在另一科，会提示核对，不能悄悄改存到另一科。

## 保留的复习规则

- 首次 1 天；做对后逐步间隔 2、4、7、15、30、60 天，做错回到短间隔。
- 周六批次顺延周一、周日批次顺延周二，后续批次依次顺延；两科各自排期。
- 周末无常规任务，可自主练习；按既定考试日期逐阶段收紧长间隔。
- 到期任务不因名额而隐藏。每次加载 20 道只是页面显示方式，可以继续加载全部任务。

## 验证

临时数据库验证科目范围、所有题目操作、识图任务、防重复保存、独立复习记录、5000 题计数与分页；无头 Chrome 验证切换、草稿归属、单科保存、45 道到期题连续加载和旧响应拦截。测试不在正式题库中增加练习题。
