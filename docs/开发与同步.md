# 开发与 GitHub 同步

## 唯一开发目录

桌面 `Prism/项目` 是实际运行的网站源码和 Git 仓库。`Prism/开发历史` 保存旧版本、规格书、测试证据与发布包，供追溯，不直接用于运行或提交。

在 `Prism/项目` 修改、验证后执行：

```powershell
git status
git pull --rebase origin main
git add README.md docs web app
git diff --cached --check
git commit -m "简述本次修改"
git push origin main
```

这是每次**完成一项修改**后的同步步骤。直接编辑 GitHub 网页不会自动修改本机文件；下次本机开发前，先 `git pull --rebase origin main`。

## 不同步的本机数据

`项目/.env` 存放 AI 密钥；`项目/data/` 存放本机数据，整个目录被 `.gitignore` 排除，不上传到公开仓库。`data/app.db` 只保存账号、密码校验值和会话；每个人的文章、学习记录、错题及图片分别保存在 `data/users/<用户ID_用户名>/learning.db` 和同目录的 `math_images/`。旧数据拆分时，系统先在 `data/backups/` 创建 SQLite 一致性备份，再复制并校验个人数据库与图片，全部通过后才清理中心库中的重复学习记录。请定期备份整个 `data/`，不要只备份 `app.db`。GitHub 的代码更新不会重置数据库；修改配置或 Python 后端代码后需要重启本机服务，前端静态文件一般刷新后更新。

公网测试入口的启动和停止按钮位于桌面 `Prism/运行工具`，地址也记录在该目录的 `Prism公网测试地址.txt`。临时 Tunnel 的地址可能变化，电脑休眠或关机后网站无法访问。

点击启动后，要等窗口显示完整网址和“公网测试已就绪”。重复点击会恢复当前仍有效的网址，并更新地址文件；如需重新申请网址，先停止再启动。启动失败会显示具体原因。操作详情见 [公网测试工具](../tools/cloudflare/README.md)。
