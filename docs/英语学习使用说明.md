# 英语学习使用说明

本说明只介绍 Prism 的**英语**模块。网站首页还有数学和信号与系统入口，它们使用独立的错题库；这里的“考研英语一”指训练难度和真题标准。

## 进入英语

打开 Prism，登录账号，在“选择科目”页点击“英语”。首次使用时如果没有当天文章，点击“生成今日内容”。生成依赖站长配置的 AI 服务，通常需要等待一段时间。每个账号拥有自己的文章、收藏、复习记录和学习统计。

如果生成失败，先保持页面打开并读完错误提示；再次点击会重新尝试。没有 AI 密钥时，站长需要在本机项目的 `.env` 配置 `AI_API_KEY`；普通测试账号不需要配置密钥。

## 每日阅读与精读

1. 先阅读英文正文。页面会记录阅读时间，开始时不会直接展示翻译和解析。
2. 读完后展开解析，对照逐段翻译，并查看重点词汇、长难句、语法和篇章逻辑。
3. 把不认识的词标为重点学习或加入素材库。复习到期后，从“今日复习”继续处理。
4. 查看“今日写作表达”，了解词语、短语和句型适合放在作文的哪一段。
5. 完成“今日仿写”：先自己写英文，再提交 AI 批改，按反馈修改后可以再次提交。

首页上方的“连续学习天数”与英语阅读活动有关。数学和信号与系统的错题数、复习数不会计入英语的词汇复习。

## 其他英语入口

| 入口 | 用途 |
| --- | --- |
| 今日复习 | 处理到期的词汇和素材。 |
| 素材库 | 查看收藏的作文表达与阅读积累，按分类查找。 |
| 学习数据 | 查看阅读、词汇和仿写的近期记录。 |
| 历史 / 真题 | 回看以往文章，导入或查看真题精读内容。 |
| 设置 | 调整备考阶段、考试日期等个人选项；管理员还可审批新账号。 |

“导入真题精读”和“粘贴真实外刊材料”会为所选材料生成解析。请确认材料来源，真题年份与篇目应与原文相符。

## 手机和公网测试

同一账号可在电脑和手机浏览器登录。当前测试地址由本机 Cloudflare Tunnel 提供；电脑、Prism 服务及 Tunnel 需要持续运行。临时 Tunnel 重启后地址通常变化，以桌面 `Prism/运行工具/Prism公网测试地址.txt` 为准。

测试时使用的是站长本机数据库，保存的文章、批改和收藏会留在本机。不要把账号密码、AI 密钥或数据库上传到公开 GitHub 仓库。
