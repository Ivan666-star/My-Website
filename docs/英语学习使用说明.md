# 英语学习使用说明

本说明只介绍 Prism 的**英语**模块。网站首页还有数学和信号与系统入口，它们使用独立的错题库；这里的“考研英语一”指训练难度和真题标准。

## 进入英语

打开 Prism，登录账号，在“选择科目”页点击“英语”。首次使用时如果没有当天文章，点击“生成今日内容”。生成依赖站长配置的 AI 服务，通常需要一到两分钟。

> 2026-10-11 起，生成、粘贴外刊、导入真题都改成了**后台任务**：点一次就立刻开始，页面每两秒自动看一次进度，跑完自己上屏；中途可以去别的页面，回来还在跑。以前那种「等两分钟然后报 524」的情况不会再出现。

如果生成失败，页面会直接给出原因；再次点击会重新尝试。没有 AI 密钥时，站长需要在本机项目的 `.env` 配置 `AI_API_KEY`；普通测试账号不需要配置密钥。每个账号拥有自己的文章、笔记、收藏、复习记录和学习统计。

## 每日阅读与精读

1. 先阅读英文正文。页面会记录阅读时间，开始时不会直接展示翻译和解析。
2. **双击单词**：正文里双击一个词（手机上先选中它），下方弹出小卡片，给出中文意思、它在**这一句里**的意思和例句。卡片上的“记入阅读笔记”可以把它收进笔记。
3. **划选填充**：选中正文里的词或句子，会浮出颜色条（黄 / 绿 / 蓝 / 粉），点“填充并记入笔记”就给这段文字上色，**同时自动记一条阅读笔记** —— 不需要再点保存。
4. **填错了怎么取消**：两种方式 —— ① 刚填充完，工具条上会有“取消刚才的填充”，点一下正文颜色和那条笔记一起删掉；② 任何时候点一下正文里已有的颜色，会弹出“取消填充 / 在笔记里看”。
5. 读完后展开解析。解析区按**两类**摆（2026-10-14 起的口径）：
   - 最上面是**中文翻译**，读完先对照它检查自己理解得对不对；
   - **🎯 日常必记**：今日词汇 + 今日写作表达 —— 这两样是“知识点”，每天要记，**会进每日复习**；
   - **📖 闲时精读**：长难句与语法 —— 想深挖的时候再看，**不进每日复习**（随时可在素材库/语法积累库里翻）。
6. 词汇**默认都按“不认识”收着**；释义给的是**考研真题里的高频义**（不是词典的全部义项），已经会的点一下“已掌握”，就不会再占待攻克数。
7. 语法只讲**一个**关键知识点，配**一个**例句。想长期记住的，点“＋ 收进语法积累库”（收进后只供查阅，不会每天提醒复习）。
8. 查看“今日写作表达”，了解词语、短语和句型适合放在作文的哪一段。
9. 完成“今日仿写”：先自己写英文，再提交 AI 批改，按反馈修改后可以再次提交。

## 看着累就调字体（Aa）

顶栏的 **Aa** 按钮打开“阅读外观”面板，可以调三样，**边调边看效果**，选完自动记住（重进页面仍在）：

| 项目 | 可选 |
| --- | --- |
| 字号 | 小 / 标准 / 大 / 特大 / 超大 |
| 行距 | 紧凑 / 标准 / 宽松 / 很宽 |
| 字体 | 衬线（阅读感，默认）/ 无衬线（笔画更清楚，长时间看更省眼） |

面板里有一段示例文字可以对照。想回到原样就点“恢复默认”。

> 如果看久了还是觉得花，通常**把行距调宽一档**比单纯放大字号更有效；屏幕小的时候“大 + 宽松”最舒服。这个设置只作用于你这台设备，不影响账号里的学习数据。

## 阅读笔记与语法积累库

首页顶栏的 📝 进入“阅读笔记”，里面有两个标签：

| 标签 | 内容 |
| --- | --- |
| 📝 阅读笔记 | 划线填充过的词、短语和句子；可以补中文意思、写自己的批注、删除。 |
| 🧠 语法积累库 | 从各篇文章里收进来的语法点，跨文章攒在一起。 |

两个标签各自带数量（如“阅读笔记（3）”），点一下就会切换，当前所在的那个是深色底。

**这些东西不会看完就过去**：每条笔记/收藏一进库就进入复习节奏（1 → 2 → 4 → 7 → 15 → 30 → 60 天），到期后出现在“今日复习”里 —— 先只给英文让你回忆，再点“看答案”自测。笔记和素材库共用同一条队列，复习卡片上会标出“阅读笔记”。

复习提醒**只针对词汇和表达**（2026-10-14 的口径）：

| 内容 | 会进每日复习吗 | 在哪里看 |
| --- | --- | --- |
| 词汇（单词） | ✅ 会 | 素材库「🔤 词汇」/ 今日复习「词汇」 |
| 表达（短语 / 句型 / 阅读笔记） | ✅ 会 | 素材库「🧩 短语」「🏗 句型」/ 今日复习「表达」 |
| 长难句 | ❌ 不会 | 素材库「📐 长难句」，随时翻阅 |
| 语法积累 | ❌ 不会 | 阅读笔记里的「🧠 语法积累库」，或素材库「🧠 语法」 |

首页上方的“连续学习天数”与英语阅读活动有关。数学和信号与系统的错题数、复习数不会计入英语的词汇复习。

## 素材库怎么分类

素材库（顶栏 📚）有两排标签，先按**类型**分，再按**来源库**分：

| 标签 | 内容 |
| --- | --- |
| 🔤 词汇 / 🧩 短语 / 🏗 句型 / 📐 长难句 / 🧠 语法 | 用户 2026-10-14 的要求：“语法在语法一栏、词汇在词汇一栏、长难句在长难句一栏”。 |
| 📝 作文素材库 / 📖 阅读积累库 | 原来的分法：能用在作文里的表达 vs 阅读里攒的表达。 |

选「长难句」或「语法」时，页面会写明这两类**不进每日复习**，并且不显示“用在作文哪一段 / 什么文体”这些筛选（它们不写作文）。其余筛选（位置、文体、主题分组、关键词搜索）照旧可用。

## 其他英语入口

| 入口 | 用途 |
| --- | --- |
| 今日复习 | 处理到期的**词汇和表达**；页面里分成「🔤 词汇」和「✍️ 表达」两栏。 |
| 素材库 | 查看收藏的表达、单词、长难句和语法，先按类型分栏，再按分类查找。 |
| 阅读笔记 | 划线填充攒下的笔记 + 语法积累库。 |
| 学习数据 | 查看阅读、词汇和仿写的近期记录。 |
| 历史 / 真题 | 回看以往文章，导入或查看真题精读内容。 |
| 设置 | 调整备考阶段、考试日期等个人选项；管理员还可审批新账号。 |

“导入真题精读”和“粘贴真实外刊材料”同样走后台任务，点一次即可，页面会自己等结果。请确认材料来源，真题年份与篇目应与原文相符。

> 篇幅较长的“阅读逻辑”和“命题视角”两个板块，按 2026-10-11 的要求暂时收起（数据仍在库里），以后需要可以再打开。

## 手机和公网

同一账号可在电脑和手机浏览器登录。固定地址是 **https://myprism.click**（`www` 前缀同样可用），由本机 Cloudflare 隧道提供；电脑、Prism 服务和隧道需要持续运行。隧道随 Windows 登录自启，也可以用桌面 `Prism/运行工具` 里的按钮手动启停，地址记录在同目录的 `Prism网站地址.txt`。

笔记、文章、批改都保存在站长本机的数据库里。不要把账号密码、AI 密钥或数据库上传到公开 GitHub 仓库。
