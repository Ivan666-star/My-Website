# 手机端筛选对齐与科目名称

## 发现的问题

1. “搜索题干 / 知识点 / 解法”的输入框比左侧“复习状态”低：输入框继承了通用的 12px 顶部间距，而下拉框没有。
2. 两类原生控件由浏览器自行计算高度，手机浏览器可能显示不同高度；固定高度时还需要给文字留足内部空间。
3. 用户截图仍显示“数学一错题库”。实际检查当前公网 JavaScript，科目名已为“英语”“数学”，标题已为“数学错题库”。截图对应旧页面；无法仅凭截图确定手机缓存或标签页的具体状态。

## 问题 1、2：同一行统一布局、间距和高度

错误代码：

```html
<div class="field-row">
  <label class="field">复习状态 …</label>
  <label class="field" style="flex:2">
    搜索题干 / 知识点 / 解法
    <input class="field-input" id="mfQ">
  </label>
</div>
```

```css
.field-input{margin-top:12px}
```

正确代码：

```html
<div class="field-row math-search-row">
  <label class="field">复习状态 …</label>
  <label class="field">搜索题干 / 知识点 / 解法 …</label>
</div>
```

```css
.math-search-row{display:grid; grid-template-columns:minmax(110px,1fr) minmax(0,2fr); align-items:start}
.math-search-row > .field{min-width:0}
.math-search-row > .field > span{white-space:nowrap}
.math-search-row select, .math-search-row .field-input{height:44px; margin-top:0; padding:6px 12px; min-width:0}
```

根因是通用输入框样式添加了单侧间距。修正为这一行单独定义两列布局，左侧保留下拉框所需空间，右侧占用更多宽度；两个控件都取消顶部额外间距并统一为 44px 高。内边距减为上下 6px，避免手机上的文字被裁切。数学和信号与系统共用该布局，均得到修正。

## 问题 3：刷新后获取更新资源

旧代码：

```html
<link rel="stylesheet" href="/static/style.css">
<script src="/static/app.js"></script>
```

修正后：

```html
<link rel="stylesheet" href="/static/style.css?v=20261009-mobile1">
<script src="/static/app.js?v=20261009-mobile1"></script>
```

同时将 Service Worker 的缓存名称更新为 `prism-v16`，预缓存地址与新资源地址一致。Service Worker 是浏览器保存网页资源、供断网时打开页面的机制。版本标识使重新获取的新页面使用新地址，减少旧资源复用；手机原先已经打开的页面仍需刷新或重新打开。

科目名称保持“英语”“数学”“信号与系统”；数学页面默认标题为“数学错题库”。说明考试难度、课程范围的“考研英语一”“数学一”仍属于考试标准，不代表页面入口名称。

## 验证结果

- 使用 Playwright，在隔离数据副本中分别运行 WebKit 和 Chromium；WebKit 与 Safari 属于同类浏览器引擎，但此验证不是在实体 iPhone 上进行。
- 验证 320、390、430 像素手机宽度及 1440 像素桌面宽度；每种引擎均检查数学、信号与系统，共 16 组。
- 两侧顶部和底部差均为 0，两控件高度均为 44px，无页面横向溢出。
- 筛选、输入搜索正常，科目名称和页面标题正确，无浏览器脚本错误。
- 检查 390 像素 WebKit 截图，确认文字可见、两个控件对齐。
- 公网静态资源检查确认最新科目名称与样式已提供。
