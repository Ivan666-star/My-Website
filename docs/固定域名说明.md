# 固定域名说明：myprism.click

本文记录 Prism 固定域名的完整做法、关键参数和故障处理。日常使用只需记住网址：**https://myprism.click**。

## 一、整体链路

```
访客浏览器 → Cloudflare 边缘（DNS：myprism.click → 隧道 CNAME）
           → Cloudflare 命名隧道（本机 cloudflared 主动外连，无需公网 IP、无需端口映射）
           → 本机 http://127.0.0.1:8848（uvicorn 运行的 Prism 网站）
```

好处：地址永久固定、自动 HTTPS、本机不需要公网 IP 或路由器端口映射、不需要 ICP 备案（流量从 Cloudflare 境外节点进出）。

| 项目 | 值 |

| 阿里云改 NS 任务号 | `86100512-70f7-4396-9f13-54e556d97e15`（`CHG_DNS` / `EXECUTE_SUCCESS`） |

## 三、常用检查

```powershell
# 隧道进程是否在运行
Get-Process cloudflared

# 隧道连接日志（应有 Registered tunnel connection）
Get-Content "C:\Users\Ivan\Desktop\Prism\.tunnel\named-tunnel.stderr.log" -Tail 20

# 公网健康检查（本机必须用 --ssl-no-revoke，原因见第五节）
curl.exe --ssl-no-revoke -s -o NUL -w "%{http_code}" https://myprism.click/api/health

# 域名解析
Resolve-DnsName myprism.click -Type A -Server 1.1.1.1
```

## 四、故障对照

| 现象 | 含义 | 处理 |
| --- | --- | --- |
| 页面显示 Cloudflare 错误 **1033** 或 **530** | 隧道没有连接上（或连接器掉了） | 双击 `启动Prism固定域名.cmd`，看日志里有没有 `Registered tunnel connection` |
| 页面显示 **502** | 隧道在，但本机网站没运行 | 启动本机网站服务（`Prism 服务`/`启动服务.bat`），确认 `http://127.0.0.1:8848/api/health` 正常 |
| 浏览器打不开、域名解析不到 Cloudflare IP | 解析被改回或域名过期 | 检查阿里云域名状态、Cloudflare 区域是否 Active、NS 是否仍是 Cloudflare 那两条 |
| 本机 PowerShell/curl 报 `CRYPT_E_REVOCATION_OFFLINE` | 本机查不到证书吊销列表（国内网络常见） | 属于本机环境问题，浏览器访问正常；命令行加 `--ssl-no-revoke` 即可 |
| 电脑休眠、关机、断网 | 网站必然无法访问 | 保持开机联网；如需长期稳定可考虑迁移到云服务器 |

## 五、注意事项

1. **不要把机密文件放进仓库**：`.cloudflared` 下的 `cert.pem`、隧道凭据 `*.json` 都不提交、不外发。
2. **阿里云侧**：不要再改 DNS 服务器，也不要删除域名；解析记录现在已经由 Cloudflare 管理（阿里云云解析控制台里的记录不再生效）。
3. **Cloudflare 侧**：不要删除 `myprism.click`、`www` 这两条指向 `<隧道ID>.cfargotunnel.com` 的 CNAME，也不要在 Zero Trust 里删掉 `prism` 隧道。
4. **自签检查的坑**：本机命令行校验 HTTPS 时若未加 `--ssl-no-revoke`，可能被证书吊销检查拖到超时，这不代表网站故障。
5. **重新搭建**（换电脑或隧道被删）：

   ```powershell
   cloudflared tunnel login                        # 浏览器里授权 myprism.click
   cloudflared tunnel create prism                 # 记下新的隧道 ID
   cloudflared tunnel route dns prism myprism.click
   cloudflared tunnel route dns prism www.myprism.click
   # 按新隧道 ID 改写 %USERPROFILE%\.cloudflared\config.yml，然后运行启动按钮
   ```

## 六、可选增强

- **始终 HTTPS / 自动跳转**：Cloudflare 面板 → SSL/TLS → Edge Certificates → 打开 *Always Use HTTPS*（默认关闭；开启后 http 访问会自动跳 https）。
- **开机自启更稳**：目前靠登录后的启动项。若希望开机即启动、不依赖登录，可用管理员权限执行 `cloudflared.exe service install` 安装成 Windows 服务（需要按 Cloudflare 文档调整注册表 `ImagePath` 与 `config.yml` 路径）。

## 七、为什么长任务不会被 524 掐断

Cloudflare 对**源站响应**有硬上限：默认 125 秒 Proxy Read Timeout，免费 / Pro / Business **都不能调**，超时即返回错误码 524 并掐断连接。而「生成今天这一套」要连续调 3 次模型（1～2 分钟），正好压在这条线上。

所以生成内容、粘贴外刊、导入真题都改成了**后台任务 + 轮询**：

```
POST /api/generate        → 立刻返回「已开始」（真正的活交给后台线程）
GET  /api/generate/status → 前端每 2 秒问一次（毫秒级请求，永远碰不到 125 秒）
跑完                       → 前端拿到结果直接上屏
```

同一个账号同类任务同时只跑一个：重复点击不会重复烧模型额度，也不会反复覆盖文章；刷新或换设备回来会接着显示进度。
