# 数学 / 信号与系统错题库使用说明

本说明只介绍**错题库**（数学一的三门课 + 专业课信号与系统）。它和英语模块完全分开：错题数、复习数不计入英语的词汇复习。

## 一、录题：拍照就行

1. 进「数学」（或「信号与系统」）→ 点「＋ 拍照录题」，**一次可以丢好几张照片**进去。
2. 照片可以直接拍，也可以从相册选。上传前会自动压到长边 2560px —— 这个清晰度直接决定下标、指数认得准不准，别手动调小。
3. 想只录照片里的**某一道**题：先用「圈题」把题号圈出来，识别时就只认这一道。
4. 识别完会列出草稿让你核对：题干、科目、专题（这几项都能改），确认没问题再一起保存。

> **每道题只保留「题干 + 最终答案」**（2026-10-12 起）：
> 拍照时模型会自己把题解出来，只给出**最终答案**；不再生成推荐解法、关键步骤、知识点、易错点那一大套解析。
> 原因是那些内容生成慢、读起来也费时间，而复习时真正需要的只是「我这道题做出来了没有」。

如果照片里印着答案，就直接用照片上的；没有就让模型解出来。
实在没算出答案的题，卡片上会标一个「缺答案」，可以点「让 AI 只算个答案」单独补一次（很快，也能自己手填）。

## 二、复习：做完点两个键

到期的错题会出现在「今天该复习的错题」里，**题干和最终答案直接印在卡片上**：

```
┌─────────────────────────────────────┐
│ [高等数学] [普通错题] [今天该复习]      │
│ 7. 设数列 …                          │
│ 最终答案  $x=2$                       │
│ [✅ 会做了]  [❌ 不会做]               │
└─────────────────────────────────────┘
```

- 自己先做一遍（答案就在下面，做完再对），然后点**会做了**或**不会做**。
- 点完**这道就从列表里消失、页面不跳走**，接着做下一道。
- 连续「会做了」会按 3 → 7 → 14 → 30 → 60 天把间隔拉长，到 5 次就归入「已掌握」。
- 「不会做」则回到明天再来一次。

错题总库里每张卡上也有同样两个键，随手点即可。

## 三、改题干 / 改答案

模型算出来的答案偶尔会错，或者题目残缺算不出来。卡片上点「**改题干 / 答案**」就能**自己填正确答案**（支持 LaTeX，例如 `$x=2$` 或 `A`）。

## 四、其他入口

| 入口 | 用途 |
| --- | --- |
| 错题总库 | 按科目 / 专题 / 复习状态筛选，展开看原图与答案 |
| 开始刷题 | 从**全部**错题里随机抽一道来刷 |
| 拍照录题 | 一次多张，识别后逐张核对再入库 |

## 五、两个模块互不串门

数学和信号与系统共用同一套复习引擎，但**列表、到期、随机刷题都只看本模块的科目**：信号的刷题不会抽出数学题，反之也一样。

## 六、数据在哪

所有错题、原图、复习记录都保存在这台电脑的 `项目/data/`（每个账号一套），**不上传、不同步**。要备份就整个 `data/` 目录一起复制。
